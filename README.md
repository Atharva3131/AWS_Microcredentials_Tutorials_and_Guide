# AWS Microcredential Tutorials

A growing collection of practical, hands-on tutorials covering **all 10
AWS microcredentials**.

I'm documenting what I learn as I work through the AWS microcredential
labs---breaking each topic into clear explanations, architecture
diagrams, configuration walkthroughs, practical examples, and
troubleshooting notes.

The goal is to make these topics easier to understand and give other
learners a useful starting point when working through the labs
themselves.

## What you'll find here

-   Step-by-step tutorials for AWS microcredentials
-   Architecture diagrams and service interaction flows
-   Practical AWS console configuration guidance
-   Code snippets, SQL examples, and configuration samples
-   Common issues, debugging tips, and validation checklists
-   Links to relevant official AWS documentation

## How to use this repository

1.  Choose a tutorial from the roadmap.
2.  Review the architecture and prerequisites.
3.  Follow the implementation steps in your own AWS environment.
4.  Use the validation and troubleshooting sections as you work.
5.  Refer to the official AWS documentation for service-specific details
    and the latest configuration requirements.

**A note before you begin:** These tutorials are learning resources, not
official AWS documentation or guaranteed one-click deployment guides.
AWS console layouts, service availability, permissions, pricing, and
SDK/library behavior can change. Always review the current AWS
documentation and understand the resources you create. Use a safe
development or lab account, and never commit credentials, secret values,
or sensitive data.
